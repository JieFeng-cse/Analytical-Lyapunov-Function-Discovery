## C1 (2026-08-05) — R 的确定方法：校准，不是搜索

**结论**：漂移不等式 `L_N V ≤ C·1_{K_R} − c·V/(α+1+log V)^α` 中的 R
有一套确定性的选取流程，**不需要任何发现式搜索**（不重新解 Lyapunov 函数）：

1. **主路线（N=2, 3）**：把 benchmark 文档里的显式参考解 V_ref 代入，数值求
   `max_{box∖K_R}[L V_ref + c·φ(V_ref)]`（SHGO/密集网格，CPU 分钟级），
   二分出使其 ≤0 的最小 R_min，取 **R = 1.25 × R_min**。
   这是"验证级"一次性计算，不是"发现级"搜索。
2. **零搜索保底规则（N=4, 5 及快速估计）**：R 取能罩住两个解析可写区域的
   最小能量水平集 ×1.25——热浴核心 `{p₁²≲1, p_N²≲2}` 与门函数过渡带
   `{|p_内| ≲ 2(p_端⁴+4)}`（阈值直接读自文档 eq.(15)）。数量级 **R ≈ 10+5N**。
3. **上界约束（防真空化）**：盒内 H_max ≥ 3–4×R；K_R 占盒体积 ≲30%
   （低 N 时是真实约束；N≥4 球体积坍缩后自动满足）。
4. **安全方向**：理论是 ∃c,C,R，R 偏大不会误拒真解，只降低判别力——
   校准可以粗，宁大勿小；判别力主要靠扩盒 + 对抗采样承担。

**依据**：N=2 门函数 ρ₂ 全开需要 |p₂| ≥ 2(p₁⁴+4)（文档 eq.15），过渡带是
V_ref 漂移估计最弱处，K_R 必须罩住它，否则参考解自己都过不了 benchmark。

## C2 (2026-08-05) — 当前动量盒 ±6 装不下参考解，必须先扩盒

**结论**：p∈[−6,6] 时 N=2 参考解的完全激活快分支（|p₂|≥8）在盒内是**空集**
——benchmark 的核心难点（快转子渐近区）在当前有限域里物理上不存在。
选 R 之前必须先把动量盒扩到 **±12（最好 ±15）**。

**依据**：rotor2 实测被平凡解秒杀（2026-08-04/05 smoke + 完整 run 均 3 epoch 内
success=True，解为非周期多项式拼凑，r=1.0）；ρ₂ 阈值代入 p₁=0 即得 |p₂|≥8 > 6。

## C3 (2026-08-05) — c 的角色与选法

**结论**：c 是证书的内在品质（λV 缩放刷不动，log 压掉缩放因子），选太大
会连真解一起排除，选太小则平凡解泛滥（rotor2 教训）。选法：校准出参考解
能达到的最大 c\*（与 C1 同一次计算），benchmark 取 **c = 0.3–0.5 × c\***。
按 N 单独校准，不一刀切（N 越大混合越慢，c\* 越小；N=5 换 α=3 另算）。

## C4 (2026-08-05) — 原论文（Zou et al. ICML 2025）无 R/c 先例可抄

**结论**：原论文是确定性 ODE 局部稳定性——固定盒 + 硬编码 margin
（V≥0.05, V̇≤−0.2，全系统一刀切、从未校准），可靠性全押在凶狠的
falsifier 链（PGD→SHGO→final_check→事后 dReal）上。该哲学在 FL 任务失效：
FL 难度在渐近尾部结构，盒子截掉快转子区后 falsifier 无处施展。
**R/c 校准 + 盒子/采样设计是 rotor 项目真正的新问题。**

## C5 (2026-08-05) — 采样与 R 的耦合

**结论**：R 越大检验环带越小，均匀撒点的有效样本比例下降（低 N 时 K_R
可占盒子 ~40%，高 N 时球体积坍缩、几乎不损失）。补救优先级：
分层采样（按能量壳，紧贴 ∂K_R 的薄壳最重要）> 对抗区域偏置
（快转子区 |p_内|≫|p_端|）> 单纯堆点。基于优化的 falsifier（PGD/SHGO）
对体积不敏感，是防"大 R + 稀疏点"漏洞的主力。

## C6 (2026-08-05) — 漂移检查的两阶段语义（已实现）

**结论**：逐点检查分两阶段——(i) 点在 K_R = {H ≤ R} 内：漂移条件直接通过
（被 C·1_{K_R} 吸收）；(ii) 点在 K_R 外：检查 LV + c·φ(V) ≤ 0。
两点澄清：豁免区用能量水平集而非坐标盒（成本相同、坐标无关、贴合定理）；
第一阶段只豁免漂移，**V ≥ 1 的正性在 K_R 内外都必须查**（C 常数无需数值
检查，紧集上自动有限）。

**依据/位置**：`utils/fl_reward.py` 的 `_terms`（reward 路径）与
`_pointwise_violation`（falsifier 路径）已按此实现：
`mask=(h>R)` 乘在 drift violation 上，positivity 无 mask。

## C7 (2026-08-05) — 漂移惩罚归一化修复：只对 K_R 外的点取均值

**结论**：reward 的 drift 项原来除以全部点数，K_R 内的零贡献点会稀释惩罚，
使 R 与惩罚强度隐式耦合（R 越大越放水）。已改为只对 H>R 的点取均值
（`utils/fl_reward.py:_terms`，n_out 归一化），并加回归测试
`test_fl_penalty_not_diluted_by_inside_KR_points`。15 个 FL 测试全过。
注意：该修复整体抬高了 drift 惩罚的数值幅度，等效于加强了 c 的实际作用——
c 的校准（C3）必须在此修复**之后**做，旧 run 的 reward 数值与新 run 不可比。

## C8 (2026-08-05) — v1 转向 guided 模板搜索：固定骨架、搜修正项

**结论**（用户拍板）：v1 不做自由形式的 V 搜索，改为固定参考解骨架
`V = 1 + e^{θH} + A·ρ·p̃₂²·exp(θp̃₂²/2)`，搜索对象是：
- **修正项系数函数 g_j**（p̃₂ = p₂ − Σ g_j(r, p_端)·I_j）：符号搜索，
  小词表 {add, sub, mul, sin, cos, const} + 变量，每槽位小表达式——
  **const token 成为必需**（答案含 −1/2、3 等系数）；
- **θ、A**：连续参数，用现成常数优化器（BFGS）拟合，不做符号搜索；
- **门函数 ρ（χ、S、阈值）**：v1 固定用文档形式，不搜。

流程：从 **N=2 重发现**开始标定（全部 g_j 已知，验证搜索器能找回它们），
再攻 N=3（文档只给前两阶，其余没人写出过）和 N=5（整串未知，猜想题）。
reward/verify 裁判系统（两阶段检查、falsifier、R/c/盒校准）全部照旧不变。

**动机**：搜索空间塌缩几个数量级；平凡解绝迹（骨架强制 coercive + 快转子
处理）；周期性自动满足；生成器不再需要发明门函数/逆幂（骨架的 I_j 包办
正则化）。p̃ 修正项正是证明里"递归选取"的部分——搜出 N≥3 的高阶项是
补全/创造数学，不是复现答案。这对应 benchmark 评估协议的 guided 赛道。

**需新建的基础设施**：骨架组装器（生成器产出 g_j 小表达式 → 拼进模板 →
现有 reward/falsifier 评估拼好的 V）+ rotor 配置加 const token。

## C9 (2026-08-05) — 槽位词表、indicator 禁令、常数机制

**结论**：
- g_j 槽位词表：`{add, sub, mul, n2, sin, cos, const}` + 变量 {r 类, 端点动量}。
  **g_j 不含快动量 p₂**（对 p₂ 的依赖全部由骨架的 I_j 承担，写进槽位语法）。
  相比现 rotor 词表去掉 div/exp（槽内不需要，只引入奇点/溢出）。
- **硬 indicator/阶跃函数禁止用于候选**——数学禁令而非工程限制：V 必须全局
  C²，生成元含二阶导，阶跃函数二阶导是分布。参考解的光滑门 χ（e^{-1/u} bump
  拼接）就是 indicator 的合法替身；C8 下门已固定在骨架里，词表无需门类 token。
  条件里的 1_{K_R} 是裁判的（两阶段检查实现），也不进词表。
- 常数两类机制：骨架标量 θ、A 用带重参数化的 BFGS（θ=½·sigmoid(t)，A=e^t）；
  槽内 const 占位符（每槽 ≤3 个）由现成 ScipyMinimize/BFGS 内层拟合。
  收尾"吸附-复验"：拟合值吸附到最近简单有理数后重过 falsifier，得精确符号解。

## C10 (2026-08-05) — 修正级数是三角（AR）结构 ⇒ 分阶段搜索

**结论**：p̃ 的修正项系数构成**三角形因果系统**——g_j 的定义方程含 g_1..g_{j-1}
（微扰级数结构：g₁=cos r₁ 消掉 dp̃/dt 的 O(1) 项后，O(1/p₂) 残差的表达式里
含 g₁，g₂ 为消它而生，依此递归）。依赖单向、永不反向。由此：

1. **联合搜索空间大部分是死区**：g₁ 错则后面全废（高阶项是 O(1/p₂) 以下的量，
   碰不到低阶残差）——适应度由前缀正确性决定；
2. **分阶段搜索**（搜 g₁→验收→冻结→搜 g₂→…）每阶段有独立验收标准：
   快区残余漂移的衰减阶数逐档改善，数值上量 log|残差| 对 log p₂ 的斜率即可；
   错误不跨阶段传播；
3. 信用分配清晰（每槽有自己的信号，联合模式只有一个总 reward）。

澄清：三角结构说的是**数学依赖方向**，与生成器选 AR 还是 diffusion 无关——
它决定的是课程顺序（先低阶后高阶），不是模型架构。
分块不是工程妥协，是把搜索的形状对齐到问题的形状。

## C11 (2026-08-05) — 生成器 A/B 保留 + 双轨制；高维展望

**结论**：
- 参考答案的真实 token 长度：g₁=2, g₂=4, g₃≈14, g₄≈40，联合序列 ≈60 token
  ——落在两臂真实分化的长度区间（与 lossless6d 同量级，diffusion 曾 2/5 胜
  transformer 0/5），并非"短到差异消失"。
- **双轨制**：联合生成轨保留 transformer vs diffusion A/B（各 1 seed 起步，
  diffusion 用 loop_20 配置；科学问题：跨槽双向条件 vs 顺序先验谁更适合
  结构化数学）；**分阶段轨是发现主力**（每步序列极短，臂差异消失，
  不分臂或用便宜臂），共享骨架组装器与裁判系统。
- 注意张力：递归依赖天然偏向顺序生成（AR 主场），diffusion 的独特筹码是
  跨槽母题复用与 remask 修订——别预设 diffusion 必赢，这正是 A/B 的价值。
- **高维展望**：槽位长度随键数~线性变胖（N=3 的 g₂=9 token，g₄ 估 80-100）；
  真正的坎在 N=4/5 的**槽位数量组合爆发**（多快转子×多 regime 补丁）且骨架
  本身不完整——搜索升级为"结构搜索"（该给哪些 regime 打补丁），token 级
  生成器不直接擅长，GP 演化/显式枚举更对路，属 v2 课题。N=3 是槽位搜索的
  极限测试。高维下裁判系统反而变便宜（K_R 体积比坍缩、falsifier 靠优化
  不靠覆盖、BFGS 维度不随状态维度涨）。

**新增未决项**：Program.cache 的 reward 陈旧问题——FL 反例池每 epoch 更新
训练点，但缓存命中的候选沿用旧点集上的 reward，永不接受新反例点的重新打分，
削弱反例池的对抗效果。修法候选：缓存只存优化后常数、reward 每 epoch 重算；
或池更新时给缓存打失效标记。等 C8 跑起来观察反例池实际作用后再定。

## C13 (2026-08-06) — 负结果：文档转录版 V_ref 在过渡带上逐点不可行

**发现**：用 eq.(17) 完整四阶级数做全 FL 校准（±15/±30 盒、θ∈[0.05,0.3]、
A∈[5,1000]、R∈[20,60] 全网格）：**全部不可行**。定位：正漂移点集中在门过渡带
{S(p₁)<|p₂|<2S(p₁)}（如 p₁≈1.4, p₂≈11-15, ρ∈(0.7,0.9)），LV_patch 高达
3e11。机制：S=p₁⁴+4 使过渡带能量随 p₁ 无界（H 可达 115+），K_R 罩不住；
带内 (1−ρ)·sin r₁ 的未平均漂移和门导数项被 A·p̃²·e^{θp̃²/2} 放大，主项
θe^{θH} 数量级上永远压不住（相差 A·p̃²/θ 倍）。手推了多种变体（S 常数化、
p₁ 截断门、e^{-θp₁²/2} 抑制因子、去 p̃² 前因子）——均只是移动问题位置。

**判断**：按文档字面转录的构造无法在任何适度 K_R 下满足逐点漂移不等式；
真实证明必然有转录未捕捉的细节（门的具体形式/指数的严格不等/或对带区的
特殊处理）。文档自己的 ⚠ 注记也承认转录不确定性。**需对照 Cuneo–Eckmann–
Poquet 2015 [2] 原文核实门结构后才能定最终验证的 (θ,A,R,c)。**

**对项目的影响**：stage 1-4 槽位搜索完全不受影响（残差目标与 θ/A/c/R 解耦，
C12 作业照跑）。被阻塞的只有 full-mode 最终验证的参数校准。

**候选解法**（待用户决策）：(a) 找 [2] 原文核实门构造；(b) 利用定理允许
任意紧集 K 的自由度，把豁免区从能量水平集扩为 K_R ∪ 过渡带邻域——在
guided 赛道合法（所有候选共享同一固定门，豁免对所有人一致公平）；
(c) 两者结合：先 (b) 解锁流程，(a) 到位后收紧。

## C28 (2026-08-10) — 决策 2 解决：原论文到手，V_ref 可行性恢复（C13/C15 撤销）

用户提供 Cuneo–Eckmann–Poquet 2015 原文。精读（Def 4.4 p.2413、Lemma 4.3、
§4 的 Ω₁/Ω₂/Ω₃ 分区论证 p.2412-2414、Prop 2.2 p.2402）后定位到 benchmark
草稿的两处偏离，**逐点不可行是草稿的实例化缺陷，不是构造本身的问题**：

1. **豁免集 K 的形状**：论文的 K = {x ∈ Ω₁∪Ω₂ : p₁²+p₃² ≤ M}——"门未全开
   且端点动量有界"，**不是能量水平集**（它含任意大的 H，因为 |p₂| 可达
   2(M^k+R)）。草稿把 K 规定为 K_R={H≤R}，是**严格更强**的要求。
2. **门参数 k、R_ρ 是"取足够大"的自由参数**（论文 Convention p.2413），
   草稿把它们钉死为 k=2、R_ρ=4。R_ρ=4 太小。
   （门的形状本身无误：草稿 χ(p₂²/S²)，0 at ≤1、1 at ≥4，等价于论文
   χ(p₂/S)，0 at ≤1、1 at ≥2。N=2 单浴下 S 只含 p₁ 也正确——无 p₃。）
   论文过渡带 Ω₂ 靠**逐点指数抑制**处理（(4.4) 的 e^{-(β/2)(p₁²+p₃²)}
   × Ω₂ 上 p₁²+p₃² ≍ |p₂|^{1/k} × Lemma 4.1 的 −C₂(p₁²+p₃²)e^{βH}），
   不靠紧集——我们此前"过渡带无法被紧集豁免"的推断因此是错的前提。
   论文的量词次序：β → (k,R_ρ) → A → M。

**数值验证（±15 盒、全四阶 V_ref、400-500k 点）**：

## C30 (2026-08-10) — const 路径第二个 bug：update_r 绕过常数优化

第一次修复（C29，spawn 安全的池 initializer）到位后暴露下一层：
`AssertionError: Constant is not callable with value None`。根因——
`Program.r`（cached_property）内部先 optimize() 再算 reward，但训练主循环

sympy 槽表达式，y_hat 根本用不到（顺带省一次全量数值求值）。
验证：单/双 const 候选经 update_r 正常拟合（−0.8676；−0.8647/+0.1184），
evaluate 正常。重提 19773xxx。

**教训**：const 支持横跨 DSO 的三条路径（p.r / update_r / GP 池），本地
单路径测试无法覆盖——今后新增功能按"三路径"清单验证。
