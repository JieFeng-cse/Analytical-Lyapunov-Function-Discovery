3 Suggested evaluation protocol
For each N, the model receives HN , LN , the target exponent α, and an allowed symbolic grammar.
It returns an expression tree for VN and numerical or symbolic values for any free parameters.
Evaluation should be split into the following stages.
6
1. Syntax and regularity. Check that the expression is real, periodic in each angle, globally
defined, and C
2
. Denominators such as 1/pi require smooth cutoffs that vanish near pi = 0.
2. Positivity and coercivity. Search for violations of VN ≥ 1 and verify growth as ∥p∥ → ∞.
3. Generator falsification. Maximize
LN VN + c
VN
(α + 1 + log VN )
α
outside KR, with adversarial sampling concentrated in fast-rotor and near-resonant regimes.
4. Tail certification. A bounded-box numerical check is not a global Foster–Lyapunov proof.
Split momentum space into asymptotic regimes and prove the sign of the leading terms in each
regime.
5. Blind versus guided scores. Run a blind task using only the dynamics, then a guided task
in which the structural reference forms (13), (21), (26), or (29) are included in the grammar
prior. Report both scores.
A practical first grammar should contain arithmetic operations, integer and learned real constants, sin, cos, exp, log, absolute or smooth absolute value, and a fixed smooth cutoff primitive.
The N = 4 and N = 5 problems are unlikely to admit short global expressions without some
mechanism for regime-dependent patching.
4 Questions left open in this draft
1. Should the benchmark require a fully global certificate, or should it also include a finite-domain
discovery track compatible with existing numerical falsifiers?
2. Should the bath temperatures and friction coefficients be fixed as above or sampled during
training to test parameter generalization, separately for the one-bath N = 2 and two-bath
N ≥ 3 cases?
3. For N = 5, should α = 3 be supplied to the model, or should the model jointly search over α
and V5?
4. Which smooth cutoff functions and piecewise constructions should be included as atomic tokens
in the discrete diffusion vocabulary?
